# 🛒 EasyMart E-Commerce Website

EasyMart is a responsive front-end e-commerce website built using HTML, CSS, and JavaScript.  
It allows users to browse products, place orders, view orders, login, and contact support.

---

## 🚀 Features

- Responsive UI Design
- Product Listing
- Product Detail Modal
- Order Placement System
- LocalStorage Order Saving
- Orders Page
- Login Page
- Contact Page
- Help & Support Page

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API
